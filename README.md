# ROMarr companion fork

An experimental companion fork of [BlizzHacker/ROMarr](https://github.com/BlizzHacker/romarr), adding a durable request dashboard and optional conversational game discovery. This is not the original project or an official upstream release.

Based on upstream commit `06378a70b94d8eb5646cd9720c52a992f5e2a09a`. Original copyright is **2026 MOVE WEIGHT**; upstream authorship is **BlizzHacker (Wade)**. The original [LICENSE](LICENSE) and [NOTICE](NOTICE) are preserved unchanged. No upstream endorsement or ownership of project branding is claimed.

The tested source is being introduced through a protected pull request. No hosted service, content, credentials, provider accounts or configured indexers are included. Operators supply their own integrations.
